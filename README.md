# Пульс Проекта — v0.2.0

Корпоративная on-premise система планирования проектов на диаграммах Ганта: направления и проекты,
несколько планов (версий) у проекта, задачи, вехи, группы, связи, пометки, исполнители, комментарии,
история изменений, снимки и откат, роли и доступы, вход через LDAP, реестр изменений.

> Документация в разработке — полный комплект (руководства пользователя, администратора и по
> развёртыванию, ADR, runbook переноса) появится в составе v0.2.0.

## Состав

| Каталог | Что |
| --- | --- |
| `backend/` | API на Flask, PostgreSQL (SQLite для разработки и тестов), миграции Alembic |
| `src/` | Клиент на Vue 3 + Pinia + Vite |
| `legacy/` | Снимок базы 1.0.1 для проверки переноса и прежняя страница Ганта для сверки поведения |
| `docs/` | Документация |

## Разработка

```bash
cd backend && python -m venv .venv && . .venv/bin/activate && pip install -r requirements-dev.txt
pytest -q && ruff check .
```

Перенос базы 1.0.x в пустую базу 0.2 со сверкой:

```bash
python scripts/migrate_on_start.py
python scripts/import_legacy.py /путь/к/puls.db --report import-report.md
```
