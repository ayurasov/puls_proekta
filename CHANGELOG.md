# CHANGELOG

## v0.2.0 — в работе

Новая платформа «Пульса Проекта» на стеке todo-planner: сервер Flask + PostgreSQL + Alembic, клиент Vue 3,
развёртывание Docker Compose. Перенос базы 1.0.1 без потерь со сверкой каждого плана. Подробности — в
[docs/versions.md](docs/versions.md).

### Сервер

- Нормализованная модель данных вместо одного JSON на проект: проекты → планы (бывшие вкладки-версии) →
  строки, пометки, исполнители, комментарии, журнал изменений, снимки ([ADR-0002](docs/architecture/adr-0002-data-model-and-concurrency.md)).
- Правки приходят операциями и применяются по полям: одновременная работа нескольких сотрудников не теряет
  ничьих изменений; конфликты видны; журнал «кто, когда, было → стало».
- Автоматические снимки плана и восстановление любого снимка; корзина проектов и планов.
- Серверные сессии в БД с отзывом при отключении сотрудника и смене пароля; CSRF; ограничение попыток входа
  ([ADR-0003](docs/architecture/adr-0003-sessions-and-security.md)).
- Роли получили смысл: «Наблюдатель» — только просмотр, «Редактор» — работа по выданным доступам
  ([ADR-0004](docs/architecture/adr-0004-roles-and-access.md)).
- Перенос базы 1.0.x (`scripts/import_legacy.py`) с обратной выгрузкой и сверкой ([ADR-0005](docs/architecture/adr-0005-legacy-migration.md)).
- Производственный календарь РФ 2025–2027 в БД с правкой администратором.
