# Release notes — v0.6.1

Ветка `v0.6.1` от `v0.6.0`. Вид прогресса на полосах плана и карточки проектов по всем планам. Миграций нет.
Обновление — `sudo sh deploy/update.sh v0.6.1` из каталога установки.

## Зачем

- В 1.0 прогресс задачи был виден издалека: выполненная часть полосы затемнялась во всю высоту. С 0.4 его заменила
  тонкая полоска по нижнему краю — её плохо видно на тёмных полосах и на общем виде плана.
- Карточка проекта на главной считала только первую вкладку. Если первая вкладка пустая (например, черновик
  следующего этапа), карточка не показывала ни прогресса, ни задач, ни вехи, хотя в других планах работа шла.
  Статистика с главной открывалась только для этой вкладки.

## Что нового

### Прогресс на полосах

**Настройки графика → Отображение → Прогресс на полосах** — плитки с образцом полосы:

| Вид | Значение `display.progressStyle` | Как выглядит |
| --- | --- | --- |
| **Заливка** (по умолчанию) | `fill` | Выполненная часть затемнена во всю высоту — как в 1.0 |
| **Полоска** | `strip` | Тонкая полоска по нижнему краю — как в 0.4–0.6 |
| **Светлый остаток** | `tint` | Сделанное — цветом задачи, оставшееся — светлым тоном того же цвета |
| **С процентом** | `percent` | Заливка и «60% · » в начале подписи полосы |
| **Не показывать** | `showProgress: false` | Без прогресса на полосах |

Цвет подписи подбирается под то, что под её центром (затемнённая часть, цвет задачи или светлый остаток).
Диаграмма, предпросмотр в настройках и выгрузка PNG, PDF и SVG рисуют прогресс одним кодом (`barProgress`).
Существующие планы без настройки показывают заливку.

### Карточки проектов и статистика

- Проект с несколькими планами — строка на каждый план (до трёх): название (открывает план), прогресс, задачи,
  в работе, просрочено, заблокировано, кнопка статистики плана. Пустой план — «задач пока нет»; больше трёх — первые
  три с задачами и «и ещё N планов». Карточка стала немного выше, футер прижат к низу.
- Основной план проекта (общий процент, сортировка по прогрессу, статистика по умолчанию, API интеграций) — первая
  открытая вкладка, в которой есть задачи.
- Ближайшая веха — по всем планам, с названием плана.
- Окно статистики с главной — переключатель планов (число задач у каждого); **Открыть проект** ведёт в выбранный
  план.
- Фильтр **Просрочены** — по всем планам; **Завершены** — все планы с задачами завершены.

## Совместимость

- `GET /api/projects`: в `plans[]` добавлено поле `stats`; прежние поля не менялись.
- API интеграций: у проектов с пустой первой вкладкой показатели теперь считаются по первой вкладке с задачами.

## Проверка

Сервер — 205 тестов, клиент — 232 модульных теста, e2e — 78 сценариев.

- Сервер: `progressStyle` — значение по умолчанию, проверка, «не показывать» с запоминанием вида, формат 1.0;
  статистика каждого открытого плана, пропуск пустой первой вкладки, архивные планы не учитываются.
- Клиент: геометрия и цвета каждого вида прогресса, подпись с процентом, `rowModel`; строки планов на карточке,
  состояние проекта по планам, ближайшая веха.
- e2e: карточка с пустой первой вкладкой и тремя планами, переход в план; статистика с переключением планов и
  кнопкой в строке плана; выбор каждого вида прогресса в настройках и его отрисовка на диаграмме.
