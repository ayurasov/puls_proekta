# Release notes — v0.2.0

Ветка `v0.2.0` от `v1.0.1`. Новая платформа «Пульса Проекта» на стеке todo-planner: сервер Flask и
PostgreSQL, клиент Vue 3, развёртывание Docker Compose ([ADR-0001](../architecture/adr-0001-platform-and-stack.md)).
Диаграмма Ганта стала частью приложения ([ADR-0006](../architecture/adr-0006-native-gantt-editor.md)). Данные 1.0.1
переносятся без потерь со сверкой каждого плана ([ADR-0005](../architecture/adr-0005-legacy-migration.md)).
Переход — [runbook](../runbooks/v0.2.0-migration-from-1.0.1.md), что найдено в 1.0.1 — [ревизия](../review/v0.2.0-revision-1.0.1.md).

## Проекты

- Главная страница: проекты по направлениям, у каждого — прогресс, число задач в работе, просроченных и
  заблокированных, ближайшая веха, уровень вашего доступа, число планов, дата изменения; поиск.
- Проекты перетаскиваются между направлениями и внутри направления; новый проект — сразу в нужное направление.
- Боковое меню: направления со списком проектов, сворачивается.

## Планы (бывшие вкладки)

- У проекта несколько планов: создать пустой, копию текущего или из JSON-файла (в том числе выгруженного из 1.0);
  переименовать двойным щелчком, перетащить, дублировать, выгрузить в JSON.
- Закрытие плана — **архив**, а не потеря данных: архивные планы открываются из меню «Архив», возвращаются во
  вкладки; удалённый план — в корзине администратора.

## Диаграмма Ганта

- Часть приложения, а не встроенная страница: единый вид, окна и подсказки.
- Задачи, вехи, группы, пометки на шкале; вложенность любой глубины; связи FS/SS/FF/SF с лагом и
  автосдвигом; временной сдвиг (просрочка или ранняя сдача) со штриховкой; прогресс; текст на полосе;
  категории с цветами и легендой; ссылка на задачу Jira.
- Шкала дни / недели / месяцы / кварталы, масштаб (Ctrl + колесо), «Весь период», «Сегодня»; выходные и
  праздники по производственному календарю РФ 2025–2027; линия «сегодня» — текущая или фиксированная дата.
- Перетаскивание полос и краёв, Ctrl — копия, перенос групп целиком; перетаскивание строк в таблице — порядок
  и вложенность; контекстные меню строки и шкалы («Подзадача», «Следующая задача (связь)», «Пометка на дату»…).
- Карточка строки сбоку: статус, сроки (датой или длительностью в календарных или рабочих днях), прогресс,
  сдвиг, ответственный, связь, вложенность, категория, текст на полосе, Jira, цвет; вкладки «Комментарии»
  (с ответами) и «История» строки.
- Поиск и фильтры по статусу, исполнителю, категории (несколько значений); активные фильтры — отдельной
  строкой с быстрым сбросом.
- Колонки слева (начало, окончание, длительность, ответственный, прогресс), свернуть/развернуть группы — у
  каждого свой вид; «Сделать мой вид видом по умолчанию» для коллег.
- Клавиатура: Insert — новая задача, Enter — карточка, F2 — переименовать, Delete — удалить, Ctrl+D —
  дублировать, стрелки, Esc, Ctrl+Z / Ctrl+Shift+Z — отменить и повторить.
- Исполнители плана связаны с сотрудниками (фото, поиск); статистика плана: статусы, сдвиги сроков,
  просроченное, ближайшие вехи, загрузка по исполнителям и группам.
- Экспорт: PNG, PDF, SVG (с легендой и подписями), CSV для Excel, JSON (открывается и в 1.0).

## Совместная работа и сохранность

- Правки сохраняются автоматически и сразу; изменения коллег появляются через несколько секунд с подсветкой.
- Одновременная работа над одним планом не теряет правок: сервер применяет изменения по полям; если вы
  перезаписали только что сделанную правку коллеги, система об этом сообщает ([ADR-0002](../architecture/adr-0002-data-model-and-concurrency.md)).
- «Сейчас на плане» — кто ещё открыл план и кто правит.
- Без связи правки копятся и отправляются, когда связь вернётся; закрыть страницу с неотправленными правками
  система не даст без предупреждения.
- «История плана»: журнал изменений «кто, когда, было → стало» (с фильтром по сотруднику) и сохранённые
  версии — автоматические и ручные, с просмотром и восстановлением.
- Лишних подтверждений нет: одна строка удаляется сразу, «Отменить» — в уведомлении.

## Администрирование

- **Сотрудники**: поиск, фильтр по роли, сортировка; роль меняется прямо в таблице; отключение без удаления
  данных (сотрудник сразу выходит со всех устройств); фото; смена пароля и способа входа.
- **Направления**: цвет, описание, порядок.
- **Доступы**: выдача сразу нескольким сотрудникам на проекты или направления целиком (включая будущие
  проекты) без дублей — «заменить уровень» или «только повысить»; список правил с массовым отзывом; «Кто что
  видит» — действующие уровни с учётом ролей.
- **Роли** получили смысл: «Наблюдатель» — только просмотр, «Редактор» — по доступам, «Менеджер» управляет
  своими проектами ([ADR-0004](../architecture/adr-0004-roles-and-access.md)).
- **Реестр изменений**: фильтры по разделу, действию, автору, проекту, датам, поиск, выгрузка CSV.
- **Корзина**: удалённые проекты и планы — восстановить или удалить навсегда.
- **Настройки**: вход через домен (LDAP / Active Directory) с проверкой подключения; производственный
  календарь — праздники и рабочие дни по годам с правкой.

## Безопасность

- Серверные сессии с хэшированными токенами; отключение, смена и сброс пароля завершают сессии; CSRF;
  ограничение попыток входа; заголовки безопасности и CSP ([ADR-0003](../architecture/adr-0003-sessions-and-security.md)).
- Исправлены уязвимости 1.0.1: подделка cookie по секрету из репозитория, выполнение кода через ссылку Jira.

## Развёртывание

- Docker Compose: PostgreSQL 16, backend (gunicorn, миграции Alembic при старте), frontend (nginx), резервное
  копирование (ежедневный `pg_dump`, хранение 30 дней, восстановление одной командой).
- Порт прежний — 39663; `deploy/update.sh` — обновление с копией перед ним и проверкой готовности.
- Перенос 1.0.1: профиль `migrate` (`docker compose --profile migrate run --rm legacy-import`), отчёт и сверка;
  репетиция `--dry-run` без записи.
- Нагрузочное тестирование на 1000–2000 сотрудников — [отчёт](../performance/loadtest-v0.2.0.md).

## Совместимость

- Сотрудники входят прежними логинами и паролями; сессии 1.0.1 не переносятся — после перехода нужно войти заново.
- Старые ссылки `/#/project/N` открывают проект.
- Наблюдатели с уровнем «редактирование» в 1.0.1 теперь только смотрят план (поменяйте роль, если нужно).
