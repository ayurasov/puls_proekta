# История версий «Пульса Проекта» (для пользователей)

Нумерация: `vX.Y.Z`, до первого релиза `X = 0`; `Y` — крупная версия, `Z` — исправления и небольшие
улучшения. Ветка в репозитории называется так же, как версия. Источник номера версии — поле `version`
в корневом `package.json`; номер виден в меню приложения.

## v0.2.0 — новая платформа (в работе)

Описание появится при завершении версии.

## История до 0.2

Версии 1.0.0 и 1.0.1 (по новой нумерации — 0.1.0 и 0.1.1) работали на прежней платформе: React + Express +
SQLite, диаграмма Ганта — отдельная HTML-страница внутри приложения. Исходный код этих версий в репозитории
не сохранился — только собранные файлы (ветка `v1.0.1`).

### v0.1.1 (1.0.1) — отображение вертикальных маркеров

- Вертикальные линии и подписи вех отображаются поверх полос задач и групп; линия «сегодня» — тоже.
- Фильтры диаграммы по статусу, исполнителю и категории (несколько значений), поиск по названию.
- Исправлено повторное отображение вехи у задачи с группой; лаг связи учитывается в окне редактирования.
