# ADR-0006. Диаграмма Ганта — часть приложения

- Статус: принято
- Дата: 2026-10-30
- Версия: 0.2.0
- Связано: ADR-0002 (операции и опрос), ADR-0004 (права)

## Контекст

В 1.0.1 диаграмма Ганта — отдельная страница `gantt.html` (≈ 900 КБ HTML со встроенным скриптом) в
`iframe`. Приложение передавало ей проект через `postMessage` и получало обратно весь проект для
сохранения. Отсюда: свой интерфейс, не похожий на остальное приложение; браузерные окна
`confirm`/`prompt`/`alert` (12 мест); нельзя показать изменения коллег; повторение логики (статусы,
календарь) в двух местах; тесты — только на отдельные функции страницы.

## Решение

Редактор написан заново внутри клиента Vue и разделён на слои:

| Слой | Где | Что |
| --- | --- | --- |
| Домен | `src/gantt/domain/*` | Чистые функции без DOM: даты без сдвига часовых поясов, производственный календарь РФ (переносы, рабочие субботы), дерево и порядок строк, фильтры, автосдвиг по связям, раскладка шкалы и подписей вех, статистика, цвета, локальное применение операций и обратные операции для отмены |
| Модель рисунка | `src/gantt/chartModel.js` | Координаты полос, вех, групп, пометок, стрелок связей, легенда — одна модель для экрана и выгрузки |
| Редактор | `src/gantt/editor.js` | Состояние плана, очередь операций и повторы, опрос изменений, присутствие, отмена/повтор, вид сотрудника |
| Интерфейс | `src/gantt/components/*` | Панель инструментов, вкладки планов, таблица и шкала (SVG), карточка строки, окна настроек, исполнителей, статистики, истории |
| Выгрузка | `src/gantt/export.js` | PNG, PDF (jsPDF), SVG — из той же модели рисунка; CSV для Excel; JSON формата 1.0 |

Поведение 1.0.1 перенесено осознанно и закреплено тестами: сценарии фильтров, связей и слоёв из тестов 1.0.1
(`tests/gantt-*.test.mjs`) переписаны на доменные модули (`legacyParity.test.js`), включая автосдвиг
FS/SS/FF/SF с лагом, ограничения подзадач рамками родителя, фильтры «любое из отмеченного внутри, все условия
между». Где 1.0.1 ошибалась (календарь только на 2026 год, сдвиг дат на часовой пояс, наложение подписей
вех), поведение исправлено.

### Интерфейс

- Все вопросы — окна приложения с понятными действиями («Удалить всё» / «Оставить вложенные»,
  «В плановый срок» / «Сегодня»…), а не окна браузера. Лишних подтверждений нет: одна строка без вложенных
  удаляется сразу, а уведомление предлагает «Отменить» (также Ctrl+Z и история плана); спрашиваем, только
  когда удаляются несколько строк или строка с вложенными.
- Таблица и шкала синхронно прокручиваются; строки виртуализированы (рисуются только видимые).
- Перетаскивание полос (сроки), краёв (длительность), групп целиком, Ctrl — копия; перетаскивание строк в
  таблице — порядок и вложенность; двойной щелчок и F2 — переименование; Insert, Delete, Enter, Ctrl+D,
  стрелки; Ctrl + колесо — масштаб.
- Действия с планом целиком (исполнители, статистика, история, настройки, экспорт) — в строке вкладок
  планов; панель инструментов — в одну строку на экранах от 1280 px.
- Наблюдатель и сотрудник с доступом «просмотр» видят ту же диаграмму без инструментов правки и с пояснением.

## Последствия

- Одна дизайн-система и одни окна во всём приложении; изменения коллег видны на диаграмме через несколько
  секунд.
- Логику диаграммы можно тестировать и развивать: 45 тестов vitest на домене и форматах, e2e-сценарии
  правки, совместной работы, истории и выгрузки.
- Старая страница сохранена только как образец для сверки поведения: `legacy/reference/gantt-v1.0.1.html`.
