# Runbook v1.0.1

## Развёртывание

1. Сделать резервную копию `puls.db`.
2. Заменить файлы приложения версией `v1.0.1`.
3. Перезапустить сервис: `sudo systemctl restart puls`.
4. Проверить статус: `sudo systemctl status puls`.

Сборка и миграция базы данных для этой правки не требуются: изменён готовый статический файл `dist/public/gantt.html`.

## Smoke-проверка

1. Открыть диаграмму с задачей и вехой на одной дате.
2. Убедиться, что вертикальная линия вехи видна поверх синей/цветной полосы задачи.
3. Проверить сплошной, пунктирный и точечный стили линии.
4. Проверить дневной, недельный, месячный и квартальный масштабы.
5. Выполнить экспорт PNG и PDF и проверить видимость вех.

## Откат

Вернуть предыдущий `dist/public/gantt.html` из commit `04d4b64c3fd10fb76c1e80a9fee2bef54f7c03ca` и перезапустить сервис.
