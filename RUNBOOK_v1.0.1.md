# Runbook v1.0.1

## Развёртывание

1. Сделать резервную копию `puls.db`.
2. Получить актуальную ветку `v1.0.1`.
3. Установить зависимости и финализировать production-артефакты:

```bash
npm ci
npm run build
npm run test:gantt
node --check dist/index.cjs
python3 -m py_compile app.py
```

4. Перезапустить сервис: `sudo systemctl restart puls`.
5. Проверить статус: `sudo systemctl status puls`.

`npm run build` в этом репозитории не пересобирает отсутствующее дерево исходников. Команда проверяет наличие отслеживаемых production-артефактов и идемпотентно применяет требуемый порядок CSS-слоёв к `dist/public/gantt.html`.

Миграция базы данных не требуется.

## Smoke-проверка

1. Открыть диаграмму с задачей и вехой на одной дате.
2. Убедиться, что вертикальная линия вехи видна поверх синей/цветной полосы задачи.
3. Убедиться, что красная линия текущей даты также видна поверх полос задач.
4. Проверить сплошной, пунктирный и точечный стили линии.
5. Проверить дневной, недельный, месячный и квартальный масштабы.
6. Проверить перетаскивание и изменение размера задачи под линией: overlays используют `pointer-events:none`.
7. Выполнить экспорт PNG и PDF и проверить видимость вертикальных линий.
