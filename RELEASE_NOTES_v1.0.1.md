# Release notes v1.0.1

## Исправлено

- Вертикальные линии вех отображаются поверх горизонтальных полос задач и групп.
- Подписи вех остаются поверх линий и полос.
- Линия текущей даты отображается поверх полос задач; именно её красный пунктир был виден на повторном скриншоте.
- Восстановлена отсутствовавшая команда `npm run build`: добавлен `script/build.mjs` для безопасной финализации и проверки отслеживаемых production-артефактов.

## Совместимость

Изменение ограничено визуальными слоями диаграммы Ганта и build-time проверкой готовых артефактов. Данные проектов, API, база данных и серверная конфигурация не изменены.

## Ограничение сборки

Репозиторий не содержит указанные в старом README каталоги исходников `client`, `server` и `shared`. Поэтому `npm run build` валидирует и финализирует уже отслеживаемые файлы `dist`, но не выполняет полную пересборку React/Express из исходников.
